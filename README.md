# 📰 NewsPulse BD

![NewsPulse BD Preview](https://news-pluse-olive.vercel.app/og-image.jpg) <!-- Update this link if you have a real OG image -->

**NewsPulse BD** is a modern, blazing-fast, and responsive digital news portal built specifically for the Bangladeshi audience. Developed with the latest Next.js App Router, it delivers real-time breaking news, trending stories, and multimedia content with an exceptional user experience.

🔗 **Live Demo:** [https://news-pluse-olive.vercel.app/](https://news-pluse-olive.vercel.app/)

---

## ✨ Features

- **🚀 Next.js App Router:** Fast server-side rendering and static site generation for SEO optimization.
- **🎨 Modern UI/UX:** Styled beautifully with Tailwind CSS v4, featuring a clean and professional editorial layout.
- **🌙 Dark Mode Support:** Seamless toggling between Light and Dark themes for comfortable reading.
- **⚡ Breaking News Ticker:** Animated real-time alerts for the latest breaking news.
- **🔊 Audio Reader:** Accessibility feature allowing users to listen to news articles.
- **📱 100% Responsive:** Flawless mobile-first design that looks great on mobile, tablet, and desktop.
- **🔖 Bookmark & Reading List:** Save articles to read later.
- **📊 Interactive Components:** Opinion polls, video modals, and dynamic categorized news sections.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, React 19)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons:** Custom SVGs (Lightweight & Scalable)
- **State Management:** React Context API
- **Animations:** Custom CSS Keyframes
- **Deployment:** [Vercel](https://vercel.com/)

## 🚀 Getting Started Locally

To run this project on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Ahteshamull/NewsPulse-BD.git
   cd NewsPulse-BD
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to see the application running.

## 📦 Deployment (Vercel)

This project is fully optimized for Vercel deployment. 

1. Push your code to GitHub.
2. Go to your [Vercel Dashboard](https://vercel.com/dashboard).
3. Click **Add New... > Project** and import this repository.
4. Ensure the **Framework Preset** is set to **Next.js**.
5. Click **Deploy**.

Alternatively, deploy via Vercel CLI:
```bash
npm i -g vercel
vercel login
vercel --prod
```
